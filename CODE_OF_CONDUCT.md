# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, assume good faith. Harassment, personal attacks, and discriminatory behavior are not tolerated in any project space — issues, pull requests, discussions, or elsewhere.

Reports: conduct@formenos.land. Maintainers will review and respond confidentially, and will take action proportionate to the violation, up to and including permanent bans from project spaces.
